# Examples

This directory contains examples of proper evidence-based engineering practices.

## Contents

- **[compliant-vs-non-compliant.md](compliant-vs-non-compliant.md)** - Side-by-side examples of banned vs. compliant claims for performance, code quality, completion estimates, and uncertainty expression.

## Key Principles

1. **Never fabricate metrics** - If you don't have measurements, say so
2. **Document methodology** - Explain how measurements were taken
3. **State baselines** - What was the "before" state?
4. **Express uncertainty** - Clearly separate verified from unverified claims
5. **Be specific** - Use numbers, tool names, and concrete criteria
