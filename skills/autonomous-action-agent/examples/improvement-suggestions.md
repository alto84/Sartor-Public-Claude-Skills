## Suggestion Lifecycle

1. **Generated**: Agent observes pattern and creates suggestion
2. **Presented**: Suggestion shown to user/orchestrator
3. **Feedback**:
   - `accepted`: Implement the suggestion
   - `rejected`: Dismiss with optional reason
   - `deferred`: Consider later
4. **Learning**: Agent adjusts future suggestions based on feedback

## Integration with Multi-Agent Workflows

When running within community-swarm or enhanced-multi-agent-orchestration:

```typescript
// Autonomous agent provides suggestions
const suggestions = await autonomousAgent.getSuggestions();

// Orchestrator can present high-priority suggestions
const important = suggestions.filter(s => s.priority === 'high');

// Other agents can incorporate accepted suggestions

```
